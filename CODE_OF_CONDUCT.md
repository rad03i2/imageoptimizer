# Code of Conduct

## Our standard

ImageOptimizer welcomes focused bug reports, documentation improvements, tests, and implementation contributions.

Expected behavior includes:

- discuss code and ideas respectfully;
- provide reproducible details for technical problems;
- use synthetic or non-sensitive images in examples and tests;
- respect licenses for sample assets;
- keep feature claims aligned with behavior that actually exists.

Unacceptable behavior includes harassment, threats, discriminatory abuse, deliberate disruption, credential disclosure, publishing another person's private data, or uploading private images without permission.

## Project spaces

This applies to issues, pull requests, reviews, discussions, and other collaboration spaces controlled by the project maintainer.

## Enforcement

Maintainers may edit, hide, lock, or remove disruptive content and may restrict participation when necessary.

Security vulnerabilities should follow [SECURITY.md](SECURITY.md) instead of being disclosed publicly.
